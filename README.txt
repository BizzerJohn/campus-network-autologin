  校园网自动登录工具 · 使用说明
════════════════════════════════════════════════

【这是什么】
一个开机自动连接校园网的小工具（适配本校锐捷认证系统）。
设置一次后，以后开机自动联网，不用再手动打开网页点「连接」。

────────────────────────────────────────────
【使用步骤】（第一次使用）
────────────────────────────────────────────
1. 确认本文件夹里有这两个文件：
      campus-login.ps1
      启动.bat

2. 双击「启动.bat」

3. 按屏幕提示输入：
      · 运营商编号 → 1 移动 / 2 电信 / 3 联通 / 4 校内网
      · 账号（学号）
      · 密码（输入时不显示，属正常）

4. 登录成功后，会问「是否开启开机自动登录?」
      → 输入 Y 回车，以后开机就自动联网了

5. 完成 ✅

────────────────────────────────────────────
【常见问题】
────────────────────────────────────────────
Q：双击启动.bat 后窗口一闪而过？
A：确认 campus-login.ps1 和 启动.bat 在同一个文件夹里。

Q：提示「多次尝试后仍未联网」？
A：多半是运营商选错、或账号密码输错了。
   重新设置：删除本文件夹里的 config.json，再双击「启动.bat」。

Q：换了账号 / 换了运营商？
A：删除 config.json，再双击「启动.bat」重新设置。

Q：第一次没开启开机自启，现在想补开？
A：在本文件夹空白处按住 Shift + 鼠标右键 →「在此处打开 PowerShell 窗口」，
   输入下面这行后回车即可：
       .\campus-login.ps1 -Autostart

Q：想取消开机自动登录？
A：按 Win+R 键，输入 shell:startup 回车，
   删除里面的「CampusAutoLogin」快捷方式即可。

────────────────────────────────────────────
【注意】
────────────────────────────────────────────
· 设置好开机自启后，请不要移动或删除本文件夹，
  否则开机自启会失效（快捷方式指向脚本当前位置）。

· config.json 里保存的是你自己的账号密码，不要发给别人。
  分享本工具给同学时，只发 campus-login.ps1 和 启动.bat 两个文件。

· 本工具只适配本校（锐捷 ePortal）认证系统。
